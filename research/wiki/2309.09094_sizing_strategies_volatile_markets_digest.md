## 2. Summary

1. **Motivation**: High-volatility markets and crisis events (the paper was written during the COVID-19 pandemic) create major challenges for algorithmic traders. The paper studies how **position sizing models** (how much capital to allocate long vs. short per trade) can reduce **Value-at-Risk (VaR)** during crisis periods while still achieving satisfactory returns, using **backtesting** as the evaluation framework.

2. **Backtesting framework and VaR formalism**: Backtesting compares historical trading outcomes against VaR predictions to judge model performance, counting how often VaR is exceeded. Let $Y_t$ be portfolio returns (profit/loss) at time $t$, with $\omega_{t-1}$ the information set available at $t-1$. If $Y_t$ has a continuous distribution, $v_\alpha(\omega_{t-1},\theta)$ is a correctly specified $\alpha$-th VaR when:
   $$p(Y_t \le v_\alpha(\omega_{t-1},\theta_0)\mid F_{t-1}) = \alpha,\quad \alpha \in (0,1)\ \forall t \in \mathbb{Z} \tag{1.1}$$
   **Worked example**: at $\alpha = 0.05$, a correctly specified model should see actual losses exceed the predicted VaR threshold on roughly 5% of trading days — if the exceedance rate is significantly higher (e.g. 12%), the VaR model under-predicts risk. Backtests in this paper use **$10 million** notional capital for simulation realism.

3. **Kelly criterion / Bernoulli trials (foundational sizing theory, Kelly 1956)**: For a gamble with win probability $p$ (where $\tfrac12 < p \le 1$) and payout $+1$, loss probability $q=1-p$ with payout $-1$, starting capital $C_0$, and betting fraction $g$ of capital each round, after $n$ trials with $m$ wins:
   $$C_n = C_0(1+g)^m(1-g)^{-m+n} \tag{3.1}$$
   The per-trial exponential growth rate is:
   $$G_n(g) = \log\left(\frac{C_n}{C_0}\right)^{1/n} = \frac{m}{n}\log(1+g) + \frac{n-m}{n}\log(1-g) \tag{3.2}$$
   Expected growth: $E[G_n(g)] = \gamma(g) = p\log(1+g) + q\log(1-g)$ (Eq. 3.3). Maximizing $\gamma(g)$ gives $\gamma'(g) = \frac{p}{1+g} - \frac{q}{1-g} = 0$, solved by the **Kelly fraction**:
   $$g^{*} = p - q,\qquad p \ge q > 0 \tag{Theorem 1}$$
   **Worked example**: if $p=0.6$ (60% win rate), $q=0.4$, then $g^{*} = 0.6-0.4 = 0.2$ — bet 20% of capital per trial to maximize long-run logarithmic growth. Note: the raw Kelly criterion doesn't transfer directly to finance since returns aren't Bernoulli-distributed; growth there is maximized via a general logarithmic utility function instead.

4. **VaR for long/short positions under a general return distribution**: assuming returns $z$ are i.i.d. with density $f_z(z) = \frac{1}{\sigma}f_{k^*}\!\left(\frac{z-\mu}{\sigma}\right)$ (Eq. 2.1, $\mu$=trend, $\sigma$=volatility), the VaR for a **long** position is:
   $$VaR_l = \mu + k^{*}_{\alpha}\sigma \tag{2.2}$$
   and for a **short** position:
   $$VaR_s = \mu + k^{*}_{1-\alpha}\sigma \tag{2.3}$$
   where $k^{*}_\alpha$ is the $\alpha$-quantile of the standardized density $f_{k^*}$, with $\alpha=0.05$ used throughout. **Worked example**: for a normally-distributed return series with $\mu=0.001$, $\sigma=0.02$, and $k^{*}_{0.05}\approx -1.645$, $VaR_l = 0.001 + (-1.645)(0.02) = -0.0319$, i.e. a 5%-probability daily loss of about 3.19%.

5. **Backtesting methodologies surveyed** (Ch. 3): the paper reviews five families of VaR backtests — (a) **Bernoulli trials / Kelly (1956)**, testing coverage via binary hit/miss sequences; (b) **Independence and joint tests**, using autocovariance of the hit sequence $H_{q,\alpha}(\theta_0)$ (Eqs. 3.7–3.13) to test for serial dependence in VaR breaches; (c) **Geometric VaR backtesting** (Eqs. 3.14–3.18), combining unconditional coverage, duration independence, and independent-VaR hypotheses into a joint likelihood-ratio statistic $LR = LR_{UC} + LR_{Dind} + LR_{Vind}$; (d) **Markov's model test** (Eqs. 3.19–3.24), modeling VaR breaches as a Markov chain and comparing conditional vs. unconditional coverage; (e) **Kalman filter backtesting** (Eqs. 3.25–3.35), a state-space regression $y_t = Z_t x_t + d_t + \epsilon_t$, $x_t = T_t x_{t-1} + c_t + \epsilon_t$, with parameters estimated by maximizing the log-likelihood $\log L = -\frac{NS}{2}\log 2\pi - \frac12\sum_s \log F_s - \frac12\sum_s \frac{v_s' v_s}{F_s}$ (Eq. 3.29), useful when the regression coefficient $\beta$ is not assumed constant over time.

6. **Data and preprocessing**: Data sourced from **Yahoo Finance**, Jan 1, 1950 – Feb 28, 2020, benchmarked against **SPY** (SPDR S&P 500 ETF, 500 large/mid-cap US companies). Tickers that started trading after 1950 were excluded for that period. The **Kolmogorov-Smirnov (KS) test** was applied to filter/validate tickers against normal-distribution assumptions, run at signal windows of 5, 10, and 20 days, using a simple long/short/flat signal rule: $-1$ if low > close, $+1$ if low < close, $0$ if equal.

7. **Technical indicators used to build the alpha factor**: RSI, Bollinger Bands, SMA/EMA, Aroon Oscillator, Price Volume Trend, Acceleration Bands, Stochastic Oscillator, Chaikin Money Flow, Parabolic SAR, Keltner Channels, Ichimoku Kinko Cloud, and Money Flow Index. Key formulas include RSI $= \frac{\mu(P_u)}{\mu(P_u)+\mu(P_d)}\times 100$ (Eq. 4.1) where $P_u(t)=\max(P(t)-P(t-1),0)$ and $P_d(t)=\max(P(t-1)-P(t),0)$; Stochastic Oscillator $\%k = \frac{c-l_4}{h_4-l_4}\times100$ (Eq. 4.4); and Money Flow Index built from $Price=(High+Low+Close)/3$, $RawMoneyFlow=Price\times Volume$, $MoneyFlowRatio=\frac{14\text{-period }{+}veMoneyFlow}{14\text{-period }{-}veMoneyFlow}$, $MFI=100-\frac{100}{1+MoneyFlowRatio}$ (Eqs. 4.5–4.8).

8. **Backtesting results — sizing/hedging comparison**: three position-sizing configurations were tested under the Independence and Joint Test: (a) equal short/long (hedge, 10%/10%) → max VaR **0.0346** at position size 90; (b) short 10% / long 20% → max VaR **0.0292** at position size 85; (c) short 20% / long 10% → max VaR **0.0232** at position size 80. This shows that **increasing short exposure relative to long exposure progressively lowers max VaR**, i.e. shorting more reduces downside tail risk in these tests.

9. **Backtesting results — model comparison**: the **Kalman filter methodology** underperformed in high-volatility conditions, relying too heavily on long positions and struggling to satisfy predefined parameters — indicating it's poorly suited to turbulent markets. The **Minimum Variance** approach gave the most promising returns and showed resilience during high-volatility periods, though it exhibited higher volatility than other methods and was predominantly long-biased.

10. **Conclusion / key finding**: across all three Independence-and-Joint-Test scenarios (hedge, long-heavy, short-heavy), **shorting stocks tends to yield higher returns during high-volatility periods**, while long positions still contribute positively to VaR-adjusted performance; pure hedging (equal long/short) is **not** shown to be the most prudent strategy in turbulent conditions. Overall, the results affirm that a well-chosen sizing model can meaningfully lower VaR and stabilize returns during crisis-level volatility.

## 3. Key Importance Topics

### Kelly Criterion as the Theoretical Basis for Position Sizing
The paper roots its sizing analysis in Kelly's (1956) log-utility growth-maximization framework ($g^{*}=p-q$), while noting the theorem doesn't transfer cleanly to finance since asset returns aren't Bernoulli-distributed.

**Why it matters:** Establishes the conceptual foundation — "how big should each bet be" — that every subsequent sizing/hedging experiment in the paper builds on. Any position-sizing module should acknowledge this Kelly-vs-real-market-distribution gap rather than applying $p-q$ naively to price data.

### Asymmetric Long/Short Sizing Reduces VaR in Volatile Regimes
The three-way sizing comparison (10/10, 10/20, 20/10 short/long splits) shows max VaR dropping monotonically as short allocation increases relative to long (0.0346 → 0.0292 → 0.0232).

**Why it matters:** This is a directly actionable, quantified result — in high-volatility regimes, skewing capital toward short exposure is a concrete risk-mitigation lever, not just a qualitative heuristic.

### Model Choice Matters More Than Sizing Alone
Kalman filter backtesting underperformed (over-reliant on long positions, poor fit in turbulence) while Minimum Variance was most resilient but noisier and long-biased.

**Why it matters:** Sizing rules interact with the underlying risk/return model; a sizing strategy tuned for one model (e.g. Kalman filter's time-varying beta) may not transfer to another (e.g. minimum-variance allocation) — model and sizing should be validated jointly, not independently.

### VaR Backtesting as a Family of Statistical Tests, Not One Formula
The paper surveys five distinct backtesting methodologies (Bernoulli trials, independence/joint tests, Geometric VaR, Markov model, Kalman filter), each targeting a different failure mode (coverage, independence, duration clustering, time-varying risk).

**Why it matters:** No single backtest fully validates a VaR/sizing model — a robust pipeline should combine unconditional coverage tests with independence tests (to catch clustered breaches) before trusting a sizing rule in production.

## 4. Ideas for Development

- **Kelly-fraction position sizer with volatility scaling** — implement $g^{*}=p-q$ estimated from a rolling win-rate on your grid/DGT trade log (Sec Data Analysis), scaled down by a volatility multiplier since raw Kelly overstates position size for non-Bernoulli returns; use as a sanity cap on the fixed fractional sizes in `GeometricGrid`.
- **Long/short exposure ratio as a risk dial** — extend `DGTStrategy` money management with a configurable short/long capital split (mirroring the paper's 10/20 vs 20/10 tests) and empirically check whether skewing toward shorts lowers realized max drawdown on your BTC/ETH data, same direction the paper found for VaR.
- **VaR backtesting harness** — add a "System Evaluation" utility that computes rolling VaR at $\alpha=0.05$ from strategy returns (Eq. 2.2/2.3) and runs an unconditional-coverage + independence test (Eqs. 3.7–3.18) to check whether your grid strategy's breach rate matches the target $\alpha$, flagging regime shifts where the model under-predicts risk.
- **Kalman-filter dynamic beta overlay** — since the paper found Kalman filter sizing weak specifically in high volatility, use this as a documented negative benchmark: if you experiment with a Kalman-filtered dynamic hedge ratio for pairs/spread trades, expect it to degrade in crisis regimes and design a volatility-regime switch to fall back to a simpler model.
- **KS-test based asset/ticker screening** — before feeding a new symbol into `load_data`/backtests, run the paper's Kolmogorov-Smirnov normality screen on its return distribution at multiple windows (5/10/20 days) to flag assets whose return distribution diverges too far from the assumptions baked into your VaR or sizing formulas.
